Подготовка к ОГЭ и ЕГЭ
Сайт для репетитора и учеников: домашние задания, тесты с баллами и оценкой, файлы, ключи приглашения, оформление по сезону или своему цвету.

Запуск
Нужен Node.js 22.13 или новее (база данных — встроенный SQLite, ставить ничего не нужно).

npm install
npm start
Откройте http://localhost:3000.

Настройки через переменные окружения:

PORT — порт (по умолчанию 3000)
DATA_DIR — где лежат база и загруженные файлы (по умолчанию ./data)
Как пользоваться
Репетитор регистрируется на вкладке «Я репетитор».
В разделе «Приглашения» создаёт ключ (на 1 ученика, на группу или без ограничений) и отправляет ученику ключ или ссылку.
Ученик регистрируется на вкладке «Я ученик» с этим ключом и попадает к своему репетитору.
Репетитор задаёт ДЗ (с файлами, всем или выбранным ученикам) и создаёт тесты: один ответ, несколько ответов, краткий ответ (число/слово, допускается несколько вариантов через «;»).
Ученик сдаёт ДЗ (текст + файлы), проходит тесты и сразу видит баллы, процент, оценку и разбор.
Репетитор проверяет ДЗ (оценка, комментарий, «на доработку») и смотрит результаты тестов и статистику учеников.
«Оформление»: тема по сезону (авто/зима/весна/лето/осень), любой свой цвет, тёмный режим, падающие украшения.
Для публикации в интернете
Подойдёт любой хостинг с Node.js (VPS, Render, Railway и т. п.). Папку DATA_DIR нужно разместить на постоянном диске и делать её резервные копии. Для работы по HTTPS поставьте перед приложением nginx или используйте HTTPS хостинга.
